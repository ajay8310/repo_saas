# Infrastructure Design Plan — Badge Feature (U1, U2, U3)

Map logical components to actual infrastructure. This is a brownfield additive feature, so almost
everything is **reuse of the existing stack**; genuinely new infra is minimal. Answer the few questions,
then tell me you're done (or delegate).

## Reuse (no new infrastructure)
- **Compute**: existing FastAPI `api` container + Celery `worker`/`beat` (Docker Compose).
- **Database**: existing PostgreSQL 16 (new tables + partitions via migration 005).
- **Cache/broker**: existing Redis 7 (new cache keys, per-IP throttle buckets, aggregation watermark).
- **Object storage**: existing S3 (new prefix for badge images; versioning for DR).
- **Encryption**: existing KMS (reused via documents linkage).
- **Networking/gateway**: existing FastAPI routing + middleware; new public router behind same ingress.
- **Dev/test**: existing docker-compose.yml + docker-compose.test.yml + LocalStack.
